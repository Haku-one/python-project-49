# СДЭК Интеграция для WooCommerce

Полная интеграция с API СДЭК для WooCommerce, которая убирает лишние поля из формы доставки и позволяет выбирать пункты выдачи на основе адреса.

## Возможности

✅ **Убирает лишние поля** - скрывает поля "Населенный пункт", "Область/район", "Почтовый индекс"  
✅ **Извлечение города из адреса** - автоматически определяет город из поля "Адрес"  
✅ **Поиск пунктов выдачи СДЭК** - через официальное API СДЭК  
✅ **Расчет стоимости доставки** - на основе веса товаров  
✅ **Интеграция с Яндекс Картами** - для получения координат городов  
✅ **Поддержка новых блоков checkout** - работает с классическим и новым интерфейсом  
✅ **Кеширование данных** - для оптимизации производительности  
✅ **AJAX поиск** - без перезагрузки страницы

## Быстрая установка

### 1. Скопируйте PHP код в functions.php

Добавьте содержимое файлов в `functions.php` вашей темы:

```php
// Скопируйте весь код из cdek-woocommerce-integration.php
// Скопируйте весь код из cdek-checkout-blocks-integration.php
```

### 2. Добавьте JavaScript файлы

Создайте папку `js` в вашей теме и поместите туда:
- `cdek-integration.js`
- `cdek-blocks-integration.js`

### 3. Настройте город отправления

В файле `cdek-woocommerce-integration.php` найдите строку:
```php
'code' => 44 // Москва (укажите ваш город отправления)
```

Замените `44` на код вашего города в системе СДЭК.

### 4. Активируйте метод доставки

1. WooCommerce → Настройки → Доставка
2. Добавить метод доставки → "СДЭК Доставка"
3. Настроить и сохранить

## Как это работает

### 1. Скрытие полей
Поля "Населенный пункт", "Область" и "Почтовый индекс" автоматически скрываются с помощью CSS и PHP хуков.

### 2. Определение города
Система извлекает город из поля "Адрес" по следующей логике:
- Берет текст до первой запятой
- Удаляет сокращения типа "г.", "город"
- Например: "Саратов, ул.Аэропорт д.1" → "Саратов"

### 3. Поиск пунктов выдачи
1. Получает координаты города через Яндекс Geocoding API
2. Ищет пункты выдачи СДЭК в радиусе 50км через API СДЭК
3. Отображает список для выбора

### 4. Расчет стоимости
- Суммирует вес всех товаров в корзине
- Если вес не указан, использует 500г по умолчанию
- Рассчитывает стоимость доставки через API СДЭК

## Настройка для продакшена

### Вариант 1: Плагин (рекомендуется)

Создайте плагин в `/wp-content/plugins/cdek-integration/`:

```php
<?php
/**
 * Plugin Name: СДЭК Интеграция
 * Version: 1.0
 */

require_once plugin_dir_path(__FILE__) . 'includes/cdek-woocommerce-integration.php';
require_once plugin_dir_path(__FILE__) . 'includes/cdek-checkout-blocks-integration.php';
```

### Вариант 2: Child Theme

Добавьте код в `functions.php` child темы для сохранения при обновлениях.

## Устранение неполадок

### Не работает поиск пунктов выдачи
1. Проверьте консоль браузера на JavaScript ошибки
2. Убедитесь, что файлы JS подключены
3. Проверьте правильность API ключей

### Не скрываются поля
1. Очистите кэш сайта и браузера
2. Проверьте приоритет CSS стилей
3. Убедитесь, что нет конфликтов с другими плагинами

### Не рассчитывается стоимость
1. Проверьте, что у товаров указан вес
2. Убедитесь в правильности кода города отправления
3. Проверьте логи ошибок WordPress
